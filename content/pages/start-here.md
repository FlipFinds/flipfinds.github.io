## 1) Install the app

## 2) Add an item and its cost

Use manual entry, or barcode/photo-assisted entry where available. Check the suggested identity against the actual item: model, size, condition and accessories matter. Enter the purchase cost even if it is zero for a free item.

## 3) Review expected profit

Enter a realistic expected sale price, then check fees and shipping assumptions. Active listing prices are asking prices; use comparable completed sales where available to judge what buyers actually paid. Estimates are not guaranteed outcomes.

If you used the web calculator, enter the item details manually in the app. There is no automatic calculator-to-inventory transfer.

## 4) Save the item and keep its status current

Record whether the item is waiting to list, listed, sold, or archived. Saving an item in FlipFinds does not publish it to eBay, Poshmark or Mercari.

## 5) Record the sale when it happens

Replace the estimate with the actual sale amount and applicable costs. An unsold item is still inventory; an expected profit is not earned profit. Include shipping discounts, fees, returns and other charges that apply.

## Local inventory and optional Cloud

Local inventory works without an account. Optional Cloud requires a connected account and eligible access, and transfers data to Cloud services. Photo backup is separate; check Settings for availability and status rather than assuming inventory sync backed up every photo.
